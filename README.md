A public DevOps and SRE knowledge base with practical Markdown notes on Linux, networking, containers, Kubernetes, CI/CD, GitOps, IaC, observability, cloud, and related tooling.

Most detailed notes are written in Russian. The structure is intentionally simple, so the repository is still easy to browse, search, and learn from on GitHub.

Best experience: open the vault in Obsidian. Internal wiki-style links and note navigation were designed with Obsidian in mind.

## Overview

This repository is meant to be a clean personal handbook for recurring SRE topics:

- Linux fundamentals and troubleshooting
- networking and load balancing
- Git, Bash, and Python for automation
- Docker, Kubernetes, and Helm
- CI/CD and GitOps
- Terraform, Ansible, and cloud basics
- Prometheus, Grafana, and logging stacks

## How to Use

Each topic is organized as a pair of files:

- `*.md` - topic index and section outline
- `*. Конспект.md` - detailed notes, commands, and practical questions

Start from the topic index, then open the deep-dive note when you want more detail.

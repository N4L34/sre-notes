# SRE Notes

Личные заметки и конспекты по DevOps/SRE: Linux, сети, контейнеры, Kubernetes, CI/CD, инфраструктура как код, мониторинг, логирование и облака.

Репозиторий можно использовать как базу знаний для повторения, подготовки к собеседованиям и систематизации практических тем. Многие разделы состоят из двух файлов:

- `*.md` - список тем и структура раздела.
- `*. Конспект.md` - подробный конспект с объяснениями, командами и типовыми вопросами.

## Как работать с заметками

1. Начать с файла со списком тем в нужном разделе.
2. Перейти в конспект, если нужна расшифровка темы.
3. Использовать команды и чеклисты как шпаргалки для практики.
4. Дополнять разделы примерами из реальной эксплуатации: инциденты, troubleshooting, конфиги и best practices.

## Для кого

Этот репозиторий будет полезен тем, кто учится DevOps/SRE, повторяет базу перед интервью или собирает личный справочник по эксплуатации Linux-систем, инфраструктуры и Kubernetes.

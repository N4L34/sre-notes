При загрузке сервера происходит примерно такая цепочка:

```
Power on
↓
Firmware: BIOS / UEFI
↓
Bootloader: GRUB
↓
Linux kernel
↓
initramfs
↓
root filesystem
↓
systemd
↓
services
↓
login / SSH / рабочая система
```

**1. BIOS / UEFI**

После включения сервер запускает firmware — BIOS или UEFI.

Она:

- проверяет железо;
- ищет загрузочный диск;
- передаёт управление загрузчику.

**2. Bootloader**

Обычно это **GRUB**.

Он:

- показывает меню выбора ядра;
- загружает Linux kernel в память;
- передаёт ядру параметры загрузки.

**3. Kernel**

Ядро Linux начинает работу.

Оно:

- инициализирует CPU, RAM, устройства;
- загружает драйверы;
- монтирует временную root-систему через `initramfs`.

**4. initramfs**

`initramfs` — это временная мини-система в памяти.

Она нужна, чтобы:

- найти диск с настоящей root filesystem;
- загрузить нужные драйверы;
- расшифровать диск, если есть encryption;
- собрать RAID/LVM, если используется.

**5. Root filesystem**

После этого ядро монтирует настоящий `/`.

Например:

```
/dev/sda2 → /
```

**6. systemd**

Ядро запускает первый userspace-процесс:

```
/sbin/init
```

В современных Linux это обычно:

```
systemd
```

У него PID 1.

**7. Services**

`systemd` запускает сервисы:

```
networksshnginxdockercronjournald...
```

**8. Система готова**

Когда нужные targets достигнуты, сервер готов:

```
multi-user.targetgraphical.target
```

Для сервера обычно важен:

```
multi-user.target
```

То есть система загрузилась, сеть поднялась, SSH доступен, сервисы работают.

Коротко одной строкой:

```
BIOS/UEFI → GRUB → Kernel → initramfs → root filesystem → systemd → services → login/SSH
```
